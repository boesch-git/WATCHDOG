# WATCHDOG
Repository for inventing a proper aftersales solution. 

Overperforming in underperformance. 

IF you read this, it means, that somebody has had a hard time in his life and it might even be you ;-)
If not - be lucky!

This is the project for the unofficial official aftersales Service Tool called WATCHDOG. 

Goal is to have a powerful tool for logging different Datapoints of a unit. 
There are different steps that have to be completed before it is working - but good things take their time.

On the wishlist is a GUI, where a Unit Type (e.g. CLIVET WiSAN-YSE1 40.2, or WSHN-XEE2 18.2, etc.) is selectable.
Then, in the background a parameterlist for the modbus communication will be loadad, and a database named with the Serial Number of the unit will be initialized. 

After an logging over a desired period of time, the log is extracted and visualized. 
The user should be able to pick the datapoints that will be seen in the graph(s).
Whether this is realized with NODE red or Graphana or whatever is yet to be defined. 

Documentation will be hopefully available.
